# Terraform AWS Project

This repository contains Terraform configuration files to provision infrastructure on AWS.

## 🚀 Features
- Infrastructure as Code using Terraform
- AWS EC2 instance provisioning
- User data scripts for server initialization
- `.gitignore` configured to exclude state files and cache
