Web Hosting on Amazon EC2

This project demonstrates how to copy website files from Amazon S3 and host them on an EC2 instance using Apache, managed with Terraform.

💡 Project Overview

Instead of using S3 static website hosting, this setup uses EC2 as the web server. Files are stored in S3, copied to EC2 via IAM role + AWS CLI, and served by Apache.

  • ✓ EC2 instance runs Apache
  • ✓ S3 bucket stores website files
  • ✓ Terraform manages infrastructure
